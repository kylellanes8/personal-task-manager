## Project Description

The Personal Task Manager is a Laravel web application used to create, organize, update, and manage daily tasks. Users can add tasks, edit task details, delete tasks, and update each task's status.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Task Status
  - Pending
  - Completed

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- Git
- GitHub Codespaces

## Task Information

Each task contains:

- Task Name
- Description
- Status
- Due Date

## How the System Works

The system follows Laravel's MVC structure:

- **Routes** handle application URLs.
- **Controller** processes task actions.
- **Model** communicates with the database.
- **Database** stores task information.
- **Blade Views** display the user interface.
